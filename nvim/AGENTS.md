This is my nvim configuration directory. 
There is a symbolic link to the `~/.config/nvim` directory.

The project should be modular, following good software practices and loose
coupling.

You can use the `reference/` directory to download the plugin repositories to
help you to read the documentation.

## Usual nvim workflow

I create a `.nvim.lua` file to set a local project, that is why the global lsp,
linters and other are not configured.
